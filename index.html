AMBLOCK

A game security project for Quest developers. Explore our planned approach to device verification, multiplayer protection and fair play.

What it is

AMBLOCK is a project aiming to help developers protect multiplayer games through server-side checks and device integrity verification.

Development is ongoing. Features listed below are planned, not confirmed operational services.

What it does

Hardware attestation
Planned checks to establish device authenticity.
Server-authoritative checks
Validate important game requests on the server.
Session protection
Reduce the risks of reused authentication requests.
Request integrity
Check whether requests have been modified.
Layered protection
Combine multiple checks rather than depending on a single safeguard.
Logging
Provide developers with useful security event records.
